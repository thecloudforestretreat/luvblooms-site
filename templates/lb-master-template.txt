============================================================
SEO MAXIMIZATION STANDARD
============================================================

Every page must include:
- unique title
- unique meta description
- canonical URL
- Open Graph tags
- Twitter tags
- favicon links if used globally
- global stylesheet include

Primary keyword should appear naturally in:
- title
- meta description
- H1
- first 100 words
- one H2
- schema where appropriate
- image alt where natural

Secondary keywords should appear naturally across body copy.
Avoid stuffing.

Each page should:
- answer intent clearly
- include internal links to adjacent pages
- include meaningful descriptive anchor text
- use crawlable text, not image-only explanations
- include alt text for meaningful images
- avoid duplicate H1s
- keep heading order clean

============================================================
MOBILE / DESKTOP UX STANDARD
============================================================

Every page must:
- stack cleanly on mobile
- avoid horizontal overflow
- keep buttons full-width on narrow screens if needed
- preserve legible text over photography
- use stable card/image dimensions
- avoid decorative clutter that hurts scanning
- keep hero copy short enough to fit well
- make forms simple and tappable

Do not:
- rely on image-only text
- hide core business information beneath excessive scroll
- use weak CTA labels everywhere
- build pages that feel like mood boards without purchase/inquiry pathways

============================================================
ACCESSIBILITY STANDARD
============================================================

Every page must:
- include a skip link
- use one H1
- preserve heading order
- use meaningful alt text
- use descriptive links
- keep buttons clearly labeled
- ensure focus states are visible
- avoid empty anchors
- label form fields
- ensure FAQ controls are keyboard accessible
